📱 采集测试机信息（Android + iOS）

      
一次采集所有已连接的 Android / iOS 设备：型号、序列号、系统、CPU/GPU、内存、存储、分辨率、MAC、WebView、版本区域、性能档位等，写入 测试机信息.xlsx。按序列号 / MAC / 型号 / 名称匹配已有行，重复采集只更新，手工维护的列（资产编号、借用人等）不会被覆盖。


      

        

          
⚙️ 一键安装会自动处理

          
    
            
  • Python 3.9+：没有就自动安装（当前用户，不需要管理员）
    • 
            
  • 独立 Python 环境 + openpyxl、pymobiledevice3，不影响电脑上其他 Python 项目
    • 
            
  • adb：找不到就自动下载 platform-tools
    • 
            
  • 苹果驱动：只检查不安装，采集 iOS 需装 iTunes（微软商店）或爱思助手
    • 
          

        

        

          
🚀 用法

          
    
            
  • Android 打开 USB 调试并授权；iPhone / iPad 解锁并点「信任此电脑」
    • 
            
  • 先关掉 Excel，双击桌面「采集测试机信息」
    • 
            
  • 结果写入 %USERPROFILE%\device-info\测试机信息.xlsx
    • 
            
  • 已有自己的表：把 Excel 拖到桌面快捷方式上，就写入那个表
    • 
          

        

      


      

        
第一次使用：一键安装

        
下载后双击运行，装完会在桌面生成「采集测试机信息」快捷方式。

        ⬇ 下载一键安装
        
更新脚本：重新运行一次一键安装即可，表格不会被覆盖。装完后下载的 .bat 可以删除。

      


      

        已经配好环境，想手动运行？
        

          
把下面两个文件放同一目录（pip install openpyxl pymobiledevice3，adb 在 PATH 中），然后执行 python 采集设备信息.py，可加 -o 表格.xlsx 指定写入的表。

            ⬇ ios采集.py（iOS 模块 + 苹果机型表）
