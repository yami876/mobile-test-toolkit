📱 手机端配置步骤

1. 连接同一 WiFi：电脑和手机必须在同一局域网下
2. 配置代理：
  • Android：WiFi 详情 → 修改网络 → 高级选项 → 代理"手动" → 填入 IP + 端口
  • iOS：WiFi 详情 → 配置代理 → 手动 → 填入 IP + 端口
3. HTTPS 抓包：访问 chls.pro/ssl（Charles）或 mitm.it 下载并安装证书，并在系统设置中"信任根证书"
4. 验证：手机访问任意网页，Charles/Proxyman 应能看到请求
