📮 飞书定时推送

把「人员数据」「版本进度」每天定时推送到飞书群。推送程序运行在你自己的电脑上（到点时电脑需要开机），每人配置自己的推送，互不影响。

没有检测到本机的推送配置页。
第一次使用：一键安装

下载后双击运行，会自动安装推送程序和运行环境（没装 Node 会自动下载免安装版，不需要管理员权限），并在桌面创建「CTC 推送配置」。

⬇ 下载一键安装

安装完成后，下载的「CTC推送一键安装.bat」可以删除；桌面的「CTC 推送配置」快捷方式请保留（误删了重新运行一次安装即可恢复）。

已经装过：

双击桌面「CTC 推送配置」（或 %USERPROFILE%\.ctc-daily\打开推送配置.bat），打开后再点这个按钮就能直接进入。

更新程序：重新运行一次一键安装，配置和登录都会保留。

🔑 CTC 登录

手动填写 utoken
怎么获取 utoken？
  • 浏览器登录 ctc-next.makeblock.com → F12 → Network → 任点一个 accurate-server 请求 → 复制请求头里的 utoken
  • 或：已执行过 ctcmcpctl login 的，在 ~/.claude.json 里 mcpServers.ctc.url 的 utoken= 参数（URL 解码后）
  • token 只保存在你本机浏览器（localStorage），不会上传到本站

      📐 统计口径
      

        
          
统计周期按周：ISO 周（CW），周一到周日；自定义：所选日期范围；均含首尾两天。下文「该周」即所选周期

          
用户反馈 Bug创建时间在该周内；发现阶段：用户反馈；状态：新创建、处理中、已解决、关闭、挂起（不含拒绝）

          
漏测 Bug创建时间在该周内；测试是否漏测：是；状态同上

          
小迭代漏测 Bug创建时间在该周内；测试小迭代漏测：是；状态同上

          
拒绝 Bug创建时间在该周内；状态：拒绝

          
拒绝原因归类按原因文字的关键词依次匹配：重复问题（重复、同 XX-123）→ 非问题 / 设计如此（设计如此、符合预期、正常现象、非 bug、产品确认）→ 无法复现 → 环境 / 配置 / 操作问题 → 已修复 / 版本问题 → 外部原因（固件、系统、第三方、硬件、后端）；都不匹配为「其他」，没填为「未填写原因」

          
说明同一个问题可能同时属于多类（如既是用户反馈又是漏测），会在各类里都列出；项目里没有对应字段时该类显示「项目无此字段」
