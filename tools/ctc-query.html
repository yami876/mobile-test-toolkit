怎么获取 utoken？
  • 浏览器登录 ctc-next.makeblock.com → F12 → Network → 任点一个 accurate-server 请求 → 复制请求头里的 utoken
  • 或：已执行过 ctcmcpctl login 的，在 ~/.claude.json 里 mcpServers.ctc.url 的 utoken= 参数（URL 解码后）
  • token 只保存在你本机浏览器（localStorage），不会上传到本站
